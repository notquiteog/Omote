---
name: photoshop
description: Edit images in an installed Adobe Photoshop using desktop control, preserving layers and checking the exported result.
argument-hint: "[image path and requested edits]"
---

Use this workflow when the user asks to work in Photoshop. Operate the installed
application with the available desktop and shell tools. Do not claim a Photoshop
integration or successful edit without observing it.

1. Inspect the operating system and take a desktop screenshot. Locate Photoshop
   and the requested document. Photoshop must be installed and signed in on the
   target desktop; if it is unavailable, explain this and offer the installed
   image-editing tools. Do not install or purchase software without authorization.
2. Open the document and inspect its dimensions, layers, and current selection.
   Work on a duplicate layer or document when possible. Keep an original file.
3. Use the desktop tools to perform the requested edits. Take a fresh screenshot
   before aiming clicks and after each meaningful operation. Use visible menus,
   keyboard shortcuts, and dialogs rather than guessing hidden state.
4. Use scripting only when the installed application's actual scripting interface
   is available. Read its local documentation first. Never pass untrusted document
   text into executable script code.
5. Save an editable PSD when layers matter and export a separate deliverable in
   the user's requested format. Verify the output path and inspect the exported
   result. Report what was changed and provide the saved paths.

The desktop tools' existing approval policy applies throughout. If the user takes
control of the pointer, stop interacting until the desktop tools permit it again.
